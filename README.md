# Uber NYC Data Analysis

This project analyzes and visualizes Uber pickup data in New York City using Python.

## Features
- Loads and combines multiple Uber CSV datasets
- Cleans and processes the data
- Extracts useful time-based features
- Visualizes pickup trends by hour, day of week, and as a heatmap
- Provides both a Python script and a Jupyter Notebook for analysis

## Requirements
Install dependencies with:
```
pip install -r requirements.txt
```

## Usage
### Python Script
Run the main analysis script to generate PNG visualizations:
```
python uber_data_analysis.py
```

### Jupyter Notebook
Open `uber_data_analysis.ipynb` in Jupyter or VS Code for interactive exploration and visualization.

## Data
Place all Uber CSV files (e.g., `uber-raw-data-*.csv`) in the project directory.

## Output
- Visualizations are saved as PNG files in the project folder.
- Interactive plots and tables are available in the notebook.
